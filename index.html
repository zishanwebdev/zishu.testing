FAQ

What is Zishu? +
Zishu is a personal AI voice assistant that you can use directly from the web.
How do I use Zishu? +
Open Zishu, tap the Orb and start speaking.
Does Zishu support voice interaction? +
Yes. Zishu is designed around voice-first interaction.
Does Zishu understand Hindi? +
Yes, Zishu supports Hindi and English interaction.
Do I need to install an app? +
No. The primary Zishu experience is available directly through the website.
Does Zishu require internet? +
Yes. AI processing requires an internet connection.
Is Zishu free? +
Zishu offers a free web version. Premium features are coming soon.
What data does Zishu collect? +
Zishu processes voice input solely to respond to your requests. No personal data is stored without consent.
